### `#01` [Accordion](https://github.com/a-Fig/Accordion)
Context-window manager for AI coding agents — a `pi` extension that renders the context window as foldable, pinnable blocks instead of lossy compaction.
Built a Conductor strategy at the **AI Hackathon 2026 @ UC Berkeley (winning project)**. Came back a month later and shipped [PR #96](https://github.com/a-Fig/Accordion/pull/96), plus the Windows release CI/CD pipeline.

### `#02` [cura](https://github.com/shahxsheel/cura)
Robotic feeding assistant — drives a Piper arm over CAN bus to deliver food/water to bedridden patients.
Built macOS support for the arm's CAN stack from scratch (`gs_usb` + SLCAN, since the vendor SDK is Linux-only) and the vision-to-arm control bridge. **17 of 19 commits.**

### `#03` [Clear-Dispatch / SIGNAL](https://github.com/aadityad12/Clear-Dispatch)
Human-in-the-loop wildfire dispatch tool — AI triages and routes 911 calls, a human dispatcher stays the only voice callers hear.
Built the full React/WebSocket frontend and the live-demo voice-AI features. **24 of 46 commits.**

### `#04` [fantastic-octo-enigma](https://github.com/shahxsheel/fantastic-octo-enigma)
Real-time driver monitoring system for Raspberry Pi — YOLO26s/ncnn object detection + MediaPipe drowsiness scoring.
Built solo, as the individual research contribution behind an Infineon-partnered internship — selected from 300+ applicants into a 5-person cohort, the only De Anza team invited to present at STEM Zone 2026.

### `#05` [Temper](https://github.com/shahxsheel/Temper)
Eval and auto-remediation tool for AI agent harnesses — tests the scaffolding around a model, not the model itself.
Built for the AI Engineer World's Fair Hackathon (Best Usage of Gemini track). Built the live multi-session dashboard and deployment pipeline.
